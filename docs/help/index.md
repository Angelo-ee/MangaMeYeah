## MangaMeYeah! 的理念与现代化意义

二十多年前问世、至今仍被奉为漫画 / 图像浏览器经典的「MangaMeeya」，在现代 PC 环境（Windows 10/11、64 位、多显示器、高分辨率屏幕）下存在以下课题：

1. **字符编码（Shift_JIS）限制**：包含表情符号、多语言字符或特殊符号的路径无法打开或出现乱码。
2. **不支持新一代格式**：浏览 WebP、AVIF、手机拍摄的 HEIC、相机 RAW（DNG/CR3/ARW 等）时不得不再开一个浏览器。
3. **社交平台特有的分割图像**：X（原 Twitter）等平台上把一张插画拆成 2~4 张或 2×2 网格发布的作品，需要手工重新排列。
4. **macOS 资源派生文件 (`__MACOSX`)**：在 Mac 上压缩的 Zip 文件会混入无用垃圾文件，需要手动解包清理后重新压缩。

**MangaMeYeah!** 完整继承了 MangaMeeya 无可匹敌的操作体系（左右键翻页、组合操作、鼠标手势、放大镜），同时以 .NET 8 / 64 位 WPF 原生实现，把现代图像收集与浏览工作流所需的功能毫不妥协地整合在一起，是一款「专注、极速的纯粹浏览器」。
