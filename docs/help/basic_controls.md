# 基本操作指南 (Basic Controls)

MangaMeYeah! 忠实再现了 MangaMeeya 传统的鼠标操作体系，只用一只手握鼠标就能舒适、快速地翻阅漫画和插画。

---

## 1. 鼠标点击操作

| 操作 | 动作 | 备注 |
| :--- | :--- | :--- |
| **左键单击** | 前进到下一页 | 跨页显示时前进 2 页 |
| **右键单击** | 返回上一页 | 跨页显示时后退 2 页 |
| **右键长按** (500ms) | **单页 ⇔ 跨页显示切换** | 可瞬间修正因封面导致的跨页单张偏移 |
| **左键长按** (500ms) | **立即退出应用程序** | 无需把光标移到窗口的「×」按钮 |
| **左键拖动** | 平移（滚动）图像 | 浏览大于屏幕的图像或放大显示时很方便 |

### 组合操作（同时按下）
不松开一个按键再点击另一个按键，即可瞬间以 1 页为单位微调。
- **按住右键并点击左键**: **前进 1 页**（即使在跨页显示中也强制只前进 1 页）
- **按住左键并点击右键**: **后退 1 页**（即使在跨页显示中也强制只后退 1 页）
- **按住右键并点击中键**: 显示右键菜单

## 2. 鼠标手势（按住右键拖动）

按住右键快速移动鼠标后松开，即可直观地执行各种命令。

| 方向 | 命令名称 | 动作 |
| :---: | :--- | :--- |
| **↓** (下) | **统一高度** | 在「统一高度(用于多张显示)」与「固定倍率(默认)」之间切换 |
| **↑** (上) | **切换全屏** | 在全屏显示与普通窗口显示之间切换 |
| **→** (右) | **显示缩略图列表** | 显示灯箱式缩略图列表浮层 |
| **←** (左) | **自动适应宽** | 宽度贴合窗口并保持纵横比，超出的高度可滚动查看 |

---

## 3. 放大镜功能（局部放大）

漫画跨页中的细小对话框文字、高分辨率插画的细节，都能跟随鼠标光标平滑放大观察。

- **放大镜开 / 关**: `L` 键 或 **中键单击**
- **调整放大倍率**:
  - `按住右键并滚动滚轮`
  - 或放大镜显示中按 `↑` / `↓` 键（125% ~ 800%）
- **调整放大镜半径（尺寸）**:
  - 放大镜显示中按 `←` / `→` 键（60px ~ 360px）
- **自动抑制顶部菜单栏弹出**:
  - 使用放大镜时，即使把光标移到画面顶端附近，菜单栏和工具栏也不会意外弹出造成干扰（可在设置中更改）。

## 5. 缩放模式

在顶部菜单「**缩放模式**」或画面右键菜单的「缩放模式」子菜单中切换。以下模式都会随窗口尺寸变化自动重新计算。

| 模式 | 说明 |
| :--- | :--- |
| **自动适应宽**（`Z` / 手势 `←`） | 让当前显示的**整体宽度**贴合窗口宽度，保持纵横比；高度超出窗口时可上下滚动查看。适合跨页、横向长图。 |
| **自动适应高**（菜单） | 让当前显示的**整体高度**贴合窗口高度，保持纵横比；宽度超出窗口时可左右滚动查看。适合超高长图、纵向连排。 |
| 其他模式 | 适应窗口大小 (`X`)、按原始尺寸显示 (`C`)、固定倍率 (`V`)、指定倍率 (`B`)、适应图像大小 (`N`)、统一高度等，行为不变。 |

- 单页、双页、纵向 / 横向多页以及 2×2 网格下，「自动适应宽 / 高」都以**当前整体版面**为缩放对象，各页之间的比例保持一致。
- 超出窗口的部分可用**左键拖动**平移查看；默认隐藏滚动条，需要时可在「环境设置」中打开。
- 勾选「**只缩小不放大**」后，这两种自动适应模式都不会把图像放大到超过原始尺寸。
- 在「其他设置」开启「**滚动条显示**」后，自适应宽 / 高会按**扣除滚动条后的可见区域**计算（图像会略小），避免滚动条占位导致额外冒出水平滚动条；切换设置会立即重算版面。

## 6. 翻页边界与滚轮缓冲

- **卷末 / 卷首会停住**：读完一卷后继续向下翻页，或到第一页继续向上翻页，画面只停住并提示「已是最后一页 / 已是第一页」，**不会自动跳到相邻的文件夹或压缩包**。左键 / 右键单击、方向键、PageUp·Down、菜单「下一页 / 上一页」、滚轮都遵循这一规则。
- **显式切卷**：`Ctrl + →` / `Ctrl + ←`、鼠标侧键（前进 / 后退）、菜单「下一个文件夹(压缩包)」/「上一个文件夹(压缩包)」。切卷逻辑参见[文件夹与压缩包](folder_and_archive.md)。
- **滚轮缓冲**（`工具 → 设置 → 操作设置`，默认 2 格，范围 0~9）：图像高于窗口时，滚轮滚到顶 / 底后不会立刻翻页 —— 先忽略 250ms 的惯性尾波，再滚动指定格数才翻页，避免触控板惯性连翻数页。`0` = 到边界立刻翻页（旧手感）。
- 内容完整装下窗口时，滚轮仍是一格一页；「自动适应高」下横向超出的部分请用**左键拖动**查看，滚轮暂不处理横向边界。
