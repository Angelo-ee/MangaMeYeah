# 基本操作指南 (Basic Controls)

MangaMeYeah! 忠实再现了 MangaMeeya 传统的鼠标操作体系，只用一只手握鼠标就能舒适、快速地翻阅漫画和插画。

---

## 1. 鼠标点击操作

| 操作 | 动作 | 备注 |
| :--- | :--- | :--- |
| **左键单击** | 前进到下一页 | 跨页显示时前进 2 页 |
| **右键单击** | 返回上一页 | 跨页显示时后退 2 页 |
| **右键长按** (500ms) | **单页 ⇔ 跨页显示切换** | 可瞬间修正因封面导致的跨页单张偏移 |
| **左键长按** (500ms) | **立即退出应用程序** | 无需把光标移到窗口的「×」按钮 |
| **左键拖动** | 平移（滚动）图像 | 浏览大于屏幕的图像或放大显示时很方便 |

### 组合操作（同时按下）
不松开一个按键再点击另一个按键，即可瞬间以 1 页为单位微调。
- **按住右键并点击左键**: **前进 1 页**（即使在跨页显示中也强制只前进 1 页）
- **按住左键并点击右键**: **后退 1 页**（即使在跨页显示中也强制只后退 1 页）
- **按住右键并点击中键**: 显示右键菜单

## 2. 鼠标手势（按住右键拖动）

按住右键快速移动鼠标后松开，即可直观地执行各种命令。

| 方向 | 命令名称 | 动作 |
| :---: | :--- | :--- |
| **↓** (下) | **统一高度** | 在「统一高度(用于多张显示)」与「固定倍率(默认)」之间切换 |
| **↑** (上) | **切换全屏** | 在全屏显示与普通窗口显示之间切换 |
| **→** (右) | **显示缩略图列表** | 显示灯箱式缩略图列表浮层 |
| **←** (左) | **适应窗口大小** | 按窗口的宽高缩放显示图像 |

---

## 3. 放大镜功能（局部放大）

漫画跨页中的细小对话框文字、高分辨率插画的细节，都能跟随鼠标光标平滑放大观察。

- **放大镜开 / 关**: `L` 键 或 **中键单击**
- **调整放大倍率**:
  - `按住右键并滚动滚轮`
  - 或放大镜显示中按 `↑` / `↓` 键（125% ~ 800%）
- **调整放大镜半径（尺寸）**:
  - 放大镜显示中按 `←` / `→` 键（60px ~ 360px）
- **自动抑制顶部菜单栏弹出**:
  - 使用放大镜时，即使把光标移到画面顶端附近，菜单栏和工具栏也不会意外弹出造成干扰（可在设置中更改）。

## 4. 键盘快捷键一览

| 按键 | 动作 |
| :--- | :--- |
| **Right** / **PageDown** | 前进到下一页 |
| **Left** / **PageUp** | 返回上一页 |
| **Home** | 跳到第一页 |
| **End** | 跳到最后一页 |
| **Space** | 单页显示 ⇔ 双页（跨页）显示切换 |
| **\\** / **\|** | 右开 ⇔ 左开切换 |
| **Z** | 缩放模式: 适应宽或高 |
| **X** | 缩放模式: 适应窗口大小 |
| **C** | 缩放模式: 按原始尺寸显示 |
| **V** | 缩放模式: 统一高度(用于双页显示) |
| **F** | 切换全屏 |
| **T** | 打开 / 关闭缩略图列表 |
| **I** | **显示图像信息窗口**（非模态，支持 Home/End） |
| **F1** | 显示用户手册（本帮助） |
| **Ctrl + O** | 打开图像文件 |
| **Ctrl + Shift + O** | 打开文件夹 |
| **Ctrl + C** | 把当前显示的图像复制到剪贴板 |
| **Ctrl + 1~4** | 把当前页面立即保存到快速保存槽位 1~4 |
| **Shift + 左右方向键** | 以 10% 为步长跳转 |
| **Ctrl + 左右方向键** | 跳到上一个 / 下一个文件夹或压缩包 |
| **Ctrl + Home** | 跳到当前创作者的开头（已在开头则跳到上一位创作者） |
| **Ctrl + End** | 跳到当前创作者的末尾（已在末尾则跳到下一位创作者的开头） |
| **Alt + V → C** | 切换拼接图像检测的开 / 关（保存到 INI） |
