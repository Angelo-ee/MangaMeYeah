# 文件夹与压缩包加载机制 (Folder & Archive System)

MangaMeYeah! 不仅能浏览普通文件夹，还能无缝连续阅读各种压缩包文件（Zip / CBZ / RAR / CBR / 7z），以及它们层层嵌套形成的层级结构，用户完全无需关心内部构造。

---

## 1. 4 种层级关系与对应设置

在漫画、插画收藏中，文件夹与压缩包的组合主要存在以下 4 种关系。MangaMeYeah! 分别按如下方式处理：

| 层级关系 | 结构示例 | MangaMeYeah! 的动作与设置 |
| :--- | :--- | :--- |
| **文件夹内文件夹** | `Volume1/Chapter1/01.jpg` | **加载子文件夹模式**（`工具(_T) > 设置(_C)... > 常规设置 1`）<br>·显示确认对话框<br>·始终加载（默认）<br>·不加载子文件夹 |
| **文件夹内压缩包** | `Volume1/Special.zip` | **文件夹内压缩包也计入子文件夹**（复选框）<br>开启时，文件夹内的 Zip 等也会作为一个子文件夹透明合并 |
| **压缩包内文件夹** | `Volume1.zip` 内的 `Ch1/01.jpg` | 作为压缩包的标准结构**始终自动支持**（无需等待解压） |
| **压缩包内压缩包** (嵌套压缩包) | `Volume1.zip` 内的 `Bonus.cbz` | **压缩包内压缩包也计入子文件夹**（复选框）<br>开启时，不向磁盘写出临时文件，直接在内存中展开 |

---

## 2. 并列（同级）文件夹的自动切换机制

### 为什么并列文件夹不一次性全部载入？
例如某部作品文件夹下有 `第1卷` ~ `第50卷` 并排摆放，如果打开 `第1卷` 时把 `第2卷`~`第50卷` 的全部图像（数万张）一次性读进同一条时间线，启动会极其缓慢，「按卷阅读」「记住上次读到的卷」这类体验也会崩溃。

因此 MangaMeeya 与 MangaMeYeah! 采用以下方式：
1. **打开文件夹时**: 只载入该文件夹（及其下属子文件夹）内的图像。
2. **到达最后一页时**: 左键单击或按 `Next`，**自动平滑切换到下一个并列（同级）文件夹**。
3. **在第一页继续后退时**: 右键单击或按 `Prev`，平滑移到上一个并列文件夹的最后一页。

### 后台预先搜索实现 0ms 切换
为在到达最后一页时能平滑进入下一个文件夹，MangaMeYeah! 会在打开文件夹的那一刻就由后台线程预先搜索并缓存「下一个文件夹」「上一个文件夹」。因此在卷末点击时不会产生磁盘读取卡顿，可以瞬间进入下一卷。

## 3. MangaMeYeah! 式层级自然顺序分组排序

当文件夹里同时存在封面图像（`Cover.jpg`）、各章节子文件夹（`Chapter 1`, `Chapter 2`...）和压缩包文件时，如果单纯按全部文件名排序，不同章节里的 `01.jpg` 会互相交错混在一起。

MangaMeYeah! 按以下规则漂亮地分组排列：

```
[父文件夹]
 ├─ Cover.jpg                ← ① 父文件夹直属的图像必定排在最前
 ├─ Chapter 1/               ← ② 子文件夹与压缩包按自然顺序（1, 2, 10...）排列
 │   ├─ 01.jpg               ← ③ 各文件夹内部的文件顺序保持不变
 │   └─ 02.jpg
 ├─ Chapter 2/
 │   ├─ 01.jpg
 │   └─ 02.jpg
 └─ Chapter 3.zip            ← ④ 文件夹内压缩包同样按自然顺序无缝合并
     ├─ 01.jpg
     └─ 02.jpg
```

即使在浏览中从菜单更改文件排序（按名称、按修改时间、按文件大小等），这个层级分组结构也会始终保持。

---

## 4. 自动忽略 macOS 资源派生文件 (`__MACOSX`)

在 Mac 上压缩的 Zip 文件里，常会自动混入与各图像对应的元数据文件（`._filename.jpg`）和名为 `__MACOSX` 的隐藏文件夹。  
MangaMeYeah! 会完全忽略并排除这些系统管理文件，用户完全不必手动解包、清理垃圾文件后重新压缩。
