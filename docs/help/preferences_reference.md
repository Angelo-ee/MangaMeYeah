# 设置参考 (Preferences Reference)

这里详细说明菜单 `工具(_T) > 设置(_C)...` 中显示的各个设置项。

---

## 1. 操作设置 (Tab 1)

可按自己的喜好定制 MangaMeeya 风格的操作手感与移动量。

- **缩放步长 (%)**: 放大 / 缩小时每次的倍率变化量（默认: 5%）。
- **固定倍率 (默认)**: 「固定倍率」缩放模式下的放大率（默认: 125%）。
- **指定倍率**: 「指定倍率」缩放模式下的放大率（默认: 170%）。
- **再次选择同一缩放模式时重置倍率**: 选中与当前相同的缩放模式时，是否把倍率重置为默认值（100%）。
- **下一页 / 上一页 步进页数**: 单击时的基本翻页数（默认: 1）。
- **PageDown/Up 步进页数**: 按下 PageDown / PageUp 键时的翻页数（默认: 10）。
- **拖动滚动量 (pixel)**: 鼠标拖动时的滚动灵敏度（默认: 1）。
- **滚动单位**: 键盘或滚轮滚动图像时的计算基准（窗口大小 / 图像大小 / 固定值）。

---

## 2. 常规设置 1 (Tab 2)

关于文件夹加载行为、打开方式与跨页封面显示的设置。

- **打开方式（从开头打开 / 从上次阅读位置打开 / 缩略图显示）**:
  决定打开文件夹、压缩包，以及「启动时自动打开上次文件」后停在哪一页（INI `StartupOpenMode`）。
  - `从开头打开`（★默认，`=1`）: **忽略断点记忆**，任何文件都从第 1 页开始，即使是刚读过的那一个。
  - `从上次阅读位置打开`（`=2`）: 恢复 `MangaMeYeah.ini` 中 `[Resume]` 段记录的页码。
  - `缩略图显示`（`=3`）: 打开后先弹出缩略图列表，起始页按断点记忆恢复，可直接从缩略图选页。
  断点记忆在退出或切换文件时始终写入，只是「从开头打开」不读取它，因此随时切回续读模式都能接着看。
  菜单「更新」重新扫描当前文件夹时会保持当前页码、也不弹缩略图，不受此设置影响。
- **加载子文件夹**:
  - `显示确认对话框`: 存在子文件夹或压缩包时，弹出是否加载的确认对话框。
  - `同时加载子文件夹`: 自动把下属全部图像与压缩包一起连续载入（★推荐）。
  - `不加载子文件夹`: 只载入所选文件夹直属的图像。
- **文件夹内压缩包也计入子文件夹**:
  浏览文件夹时，把同级或子文件夹内的压缩包文件（`.zip`, `.rar` 等）也作为一个子文件夹透明合并载入。
- **压缩包内压缩包也计入子文件夹**:
  直接展开压缩包内部再嵌套的压缩包（`.zip` 内的 `.cbz` 等）并纳入浏览对象。
- **为扉页在首页前添加空白页**:
  跨页显示时，让封面（第 1 张）单独显示，使第 2 张起按原本的跨页配对对齐的空白页插入设置。

## 3. 常规设置 2 (Tab 3)

关于放大镜与背景色的设置。

- **放大镜半径 / 放大倍率**: 放大镜的直径尺寸（默认: 140px）与局部放大倍率（默认: 2.0 倍）。
- **放大镜形状**: 可选择圆形放大镜或方形放大镜。
- **显示边框 / 放大镜范围不超出屏幕**: 放大镜外框的显示，以及防止超出画面被裁切。
- **使用放大镜时抑制菜单与工具栏弹出**:
  使用放大镜时，即使把光标移到画面顶端附近，也会抑制菜单栏等意外弹出（★推荐）。
- **背景设置 / 书架背景设置**:
  主视图留白背景色，以及缩略图列表的背景色。点击右侧「选择颜色...」按钮，可从 Windows 标准调色板直观指定。

## 4. 其他设置 (Tab 4)

关于窗口行为与系统集成的设置。

- **禁止多开**:
  开启后，从资源管理器等处打开另一张图像时不会新建窗口，而是把文件转交给已有的 MangaMeYeah! 窗口并置顶。
- **退出时保存窗口位置和大小**:
  下次启动时忠实还原退出时的窗口尺寸与位置（显示器坐标）。
- **启动时自动打开上次打开的文件**:
  启动时立即打开上次阅读的文件夹或压缩包；起始页由「常规设置 1」的打开方式决定（默认「从开头打开」，即从第 1 页开始）。
- **滚动条显示**:
  显示 / 隐藏图像视图的滚动条。开启后滚动条会占用视图内部空间，因此**所有自适应缩放模式都按「扣除滚动条后的可见区域」计算**，图像会比关闭时略小（约一个滚动条宽度），但不会再因滚动条占位而额外冒出水平滚动条。切换该设置会立即重新计算版面。
- **全屏时自动隐藏鼠标光标 / 始终置顶**:
  用于专注看视频或阅读的光标隐藏与窗口置顶设置。

---

## 5. 缓存设置 (Tab 5)

调整内存占用与预加载速度之间平衡的设置。

- **解码缓存数**: 保留已解码位图的张数（默认: 32 张）。
- **启用缩放缓存**: 按显示器分辨率缓存缩小后的位图，降低内存与绘制负载（默认: 开）。
- **预加载数(前进方向 / 后退方向)**: 在后台预先解码的张数（默认: 各 4~6 张）。※自动拼接图像检测建议前进方向设为 4 张以上。
- **预加载线程优先级**:
  - `最低`: 把对 UI 线程的干扰降到最低（面向节能型 PC）
  - `通常`: 标准多核 PC 的最佳平衡（★默认）
  - `最高`: 以最快速度预加载下一页
- **缓存容量上限 (MB)**: 缓存合计内存上限（默认: 2048 MB）。

---

## 6. 设置的保存位置与文件构成

MangaMeYeah! 的全部设置、快速保存目标，以及最后读到的页（断点信息），都会自动保存在与应用程序本体同一文件夹下的 **`MangaMeYeah.ini`** 中。

- **文件格式**: INI 格式（文本文件）
- **字符编码**: UTF-8（无 BOM）
- **特点**:
  - 不使用注册表，因此把整个文件夹移到 U 盘或其他盘符也能原样继承设置运行，属于便携设计。
  - 可用记事本等文本编辑器直接打开查看、备份和编辑。
  - 首次启动时，若存在旧版 `MangaMeYeah.settings.json` 或 MangaMeeya（`C:\win32\MangaMeeya_74b\MangaMeeya.ini`），会自动继承其设置。
